<QuickAnswer>
Use **243 in the full release** and **235 in the demo**. The code changed between builds.
</QuickAnswer>

## Full game code: 243

During “Preparing the Reception,” dust the three portraits. Each character performs a countable action:

- Alexandra raises **2** fingers.
- Aldous moves his watch **4** times.
- William blinks **3** times.

The pictures on the box request them in **Alexandra → Aldous → William** order, producing **243**. The candle inside is needed for the chandelier.

## Demo code: 235

The demo presents the same idea with a different set of signals. Clicking the portraits yields Alexandra **2**, Aldous **3**, and William **5**. Enter **235** to take the sugar used in the demo porridge recipe.

## Why the online answers disagree

Many guides were published when only the October 2025 demo existed. The final game launched on August 13, 2026 and revised this puzzle. Check whether a guide says “demo” before assuming the number is current.
