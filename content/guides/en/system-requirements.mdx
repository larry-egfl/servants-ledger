<QuickAnswer>
The published minimum is a **2.4 GHz dual-core CPU and 1 GB RAM on Windows**. The macOS listing asks for **Big Sur 10.16 or later** and 200 MB memory. In practice, the Steam client itself requires a modern supported OS.
</QuickAnswer>

## Windows minimum

- OS shown by the game listing: Windows 7, 8, 10 or later
- Processor: 2.4 GHz dual core
- Memory: 1 GB RAM

Steam no longer supports Windows 7 or 8, despite older game requirement text still naming them. For a Steam installation, use Windows 10 or later.

## macOS minimum

- macOS Big Sur 10.16 or later
- 200 MB memory listed

The game is a hand-drawn 2D point-and-click adventure, so its published hardware floor is modest. If the demo runs well on the same machine, that is the most useful compatibility check before buying the full version.
