<QuickAnswer>
Windows 公布的最低要求是 **2.4 GHz 双核处理器与 1 GB 内存**；macOS 页面列出 **Big Sur 10.16 或更高版本**及 200 MB 内存。实际通过 Steam 安装还需使用其当前支持的系统。
</QuickAnswer>

## Windows 最低配置

- 商店文字：Windows 7、8、10 或更高；
- 处理器：2.4 GHz 双核；
- 内存：1 GB RAM。

需要注意：Steam 已不再支持 Windows 7 和 8，即使较旧的游戏配置文字仍列出它们。通过 Steam 安装时，应使用 Windows 10 或更新系统。

## macOS 最低配置

- macOS Big Sur 10.16 或更高；
- 页面列出 200 MB 内存。

游戏采用手绘 2D 点击解谜形式，公开硬件门槛不高。购买前先运行同一游戏的免费试玩版，是最直接的兼容性测试。
